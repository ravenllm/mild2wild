## What the booking request flow does

Customers can submit a website booking request with:

- customer name
- phone/email
- requested service
- preferred staff member, when compatible with the selected service
- preferred date/time
- notes or inspiration details

The website validates the request before accepting it. Invalid requests, fake services, or incompatible staff/service choices are rejected.

Accepted booking requests are routed into the dashboard so Caitlin can review and follow up. Staff-specific requests are tied to that staff member's calendar lane.

## What the dashboard does

### Caitlin / owner admin

Caitlin's owner/admin account can:

- see all staff calendars
- open any individual staff calendar
- review website booking requests
- add appointments or blocked time to any calendar
- manage public staff profiles
- edit bios, colors, templates, portfolios, and social/profile details
- create future staff profiles from the dashboard template

### Staff accounts

Staff accounts are scoped. A staff member can:

- log in to the dashboard
- open their own calendar
- add/edit appointments or blocked time only for their own lane
- view booking requests routed to their own calendar lane

Staff accounts do not edit public profile pages. Caitlin/admin handles public bios, colors, templates, and portfolios.
